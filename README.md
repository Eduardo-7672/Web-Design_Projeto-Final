# Ervas Tecnológicas — site institucional

Site responsivo desenvolvido em HTML, CSS e JavaScript puro.

## Como executar
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Não é necessário servidor para visualizar a versão demonstrativa.

## Estrutura
- `index.html` — estrutura e conteúdo
- `css/style.css` — identidade visual e responsividade
- `js/main.js` — menu, FAQ, animações e formulário demonstrativo

## Observação importante
Esta versão é institucional/informativa. Não implementa venda, checkout, aquisição ou instruções de uso de cannabis. Qualquer funcionalidade comercial ou conteúdo médico específico deve passar por validação jurídica e regulatória antes de publicação.


## Versão didática
Os arquivos HTML, CSS e JavaScript possuem comentários explicativos nos principais blocos.
Eles indicam:
- o papel de cada seção do HTML;
- a função dos principais grupos de estilos no CSS;
- o que cada interação do JavaScript faz;
- como menu, FAQ, animações e formulário funcionam em conjunto.
